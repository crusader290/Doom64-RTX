Doom64-RTX @VERSION@, commit @COMMIT@

Requires your own Doom 64 ROM (.z64/.n64/.v64). No ROM is included.

New in 0.5.0:
- Fix MAP01 integer-divide crash in BSP bounding-box projection. Windows crash
  reports include fault registers and module-relative addresses for diagnosis.
- Immersive gore: bounded blood sprays, overkill gibs, wall/floor splashes,
  gravity and fade. Cosmetic randomness does not alter gameplay RNG.
- Aggressive defaults: 120 FPS, always run, faster weapon switching/firing,
  stronger kick with more knockback and a shorter cooldown.
- Cleaner retro main/settings menus with scalable Share Tech Mono text,
  compact rows, contextual help, audio volume controls and PC key prompts.
- Remove console password/storage/controller menus from PC flows. Use native
  save/load slots, F5/F9 and level-start autosaves.
- One auto-loaded packs/doom64rtx-visuals.pk3 combines compatible Retribution
  sprites, ceiling-light textures and RT materials. Credits/manifest included.
- Root build.sh/build.bat download dependencies and initiate builds.

Validation: Linux and MinGW Windows builds; sanitizer math/gore checks;
GL combat traces; Vulkan and RT smoke; native Windows MAP01 run.
Original reported crash camera state was unavailable for exact replay.

Known limitations: general GZDoom ZScript/DECORATE/ACS and UDMF map support
is not implemented in this milestone. Animation/sound upgrades and a bounded
add-on compatibility layer are planned as subsequent tested releases.
RT performance and lighting vary by GPU. MSVC remains experimental.

Texture pack assets retain upstream attribution and licence status; see
packs/CREDITS.txt. Share Tech Mono font is SIL OFL; see assets/fonts/.
