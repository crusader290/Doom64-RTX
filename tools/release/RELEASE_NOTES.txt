Doom64-RTX @VERSION@, commit @COMMIT@
Requires your own Doom 64 ROM (.z64/.n64/.v64). No ROM is included.

New in 0.5.1:
- Native recoil, turn inertia, breathing, impact feedback and a 13-frame boot
  animation adapted from Brutal Doom Platinum. Kick impact matches extension.
- Four attributed sound upgrades: pistol, melee impact, flesh/slop and kick.
  Preloaded PCM, stereo positioning, volume/pause controls and bounded reverb.
- Combat Animation and Immersion Sounds settings; both default to enabled.
- Main menu gains Quit Game. Console password/storage controls remain removed.
- Fix backward weapon selection underflow when the chainsaw is not owned.
- Reset stale macro references between maps and restore loaded macro geometry.
- Bound ZIP decompression; native Windows downloader bundles SDL's libiconv.

Retains 0.5.0: divide-crash fix/diagnostic logs, heavy cosmetic gore, faster weapons,
stronger kick, 120 FPS default, retro text/settings and one consolidated PK3.

Validation: Linux, MinGW Windows and native Windows builds; sanitizer math/gore,
animation and audio tests; 1050-frame on/off gameplay traces match; native Windows
RT combat 1000 frames; actual slot save/load and backward weapon crash replay pass.

General ZScript/DECORATE/ACS execution and UDMF maps remain unsupported. Subsequent
milestones will port selected add-on behaviors to this native engine. Demo playback
and recording disable modern combat effects. RT performance varies by GPU.

Imported assets retain upstream provenance/licence status. See packs/CREDITS.txt,
credits/brutaldoom in the PK3 and assets/sounds/SOURCES.txt. Share Tech Mono is SIL OFL.
