Doom64-RTX @VERSION@ (preview), commit @COMMIT@

No game data is included. Put your own Doom 64 ROM (.z64, .n64 or .v64; USA, USA Rev 1,
Europe or Japan) next to the executable or in the folder you start it from.

Working: ROM auto-detection, game, menus, Vulkan renderer, OpenGL fallback (automatic if
Vulkan fails), keyboard/mouse/gamepad, sound and music (N64 synth), 4:3 / 16:9, log file
with crash reports.
New in 0.2: save/load anywhere (pause menu, title menu, F5 quicksave, F9 quickload, auto
save at each level start), mouse look with free aim, jumping (Space), weapon keys 1-8,
aim down sights (right mouse), kick (V), 30/60/120 fps (interpolated, game logic stays
30 Hz), Options > Graphics and Options > Gameplay, F7 debug page + stats overlay,
crosshair, extra gore, fast weapon switching.
Preview: ray traced world (F10 or Options > Graphics; needs VK_KHR_ray_query).
Known issue: some see-through wall textures (grates) mostly vanish with ray tracing on.

If something goes wrong, send doom64rtx.log (next to doom64rtx.ini: the program folder
for this portable package, otherwise %APPDATA%\Doom64RTX\Doom64RTX on Windows or
~/.local/share/Doom64RTX/Doom64RTX on Linux). doom64rtx.old.log is the previous run.

Keys: F5/F9 quicksave/quickload, F7 debug, F10 ray tracing, F11 fullscreen, F12 screenshot.
See README.md.
Linux build needs glibc 2.39+ (built on Ubuntu 24.04); libSDL3 is bundled.
Windows build: x86-64, MinGW-w64; SDL3.dll is bundled.
